# Code of Conduct

## Our standard

FB Components aims to maintain a professional, welcoming, and constructive open-source community.

Participants are expected to:

- communicate respectfully
- discuss ideas and code rather than attacking people
- give technical feedback in a useful and specific way
- respect different levels of experience and different backgrounds
- accept reasonable review feedback
- avoid harassment, threats, discrimination, or intimidation
- avoid publishing another person's private information without permission

## Unacceptable behavior

The following behavior is not acceptable in project spaces:

- personal attacks or insults
- discriminatory or demeaning comments
- sexual harassment or unwanted sexual attention
- deliberate intimidation or threats
- sustained disruption of technical discussions
- spam or abusive self-promotion
- publishing private or confidential information without authorization
- knowingly submitting malicious code

## Scope

This applies to GitHub issues, pull requests, discussions, code reviews, releases, and other official FB Components collaboration spaces.

## Enforcement

Maintainers may warn, close or lock discussions, reject contributions, restrict participation, or permanently block participation depending on severity and repetition.

## Reporting

For conduct issues that should not be handled publicly, use an appropriate private GitHub reporting or repository-owner contact channel. Do not expose sensitive personal information in a public issue.
